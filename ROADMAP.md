# Personal website roadmap

A one-page, minimal site with three sections: **About me**, **Featured projects**, **Contact**.
Plain HTML + CSS — no frameworks, no build step — hosted free on GitHub Pages.

## Phase 1 — Set up (done)
- [x] Repo cloned locally, work on the `site-setup` branch
- [x] Folder structure: `index.html`, `styles.css`, `assets/` (CV + project images)
- [x] CV copied to `assets/Maria-Suarez-CV.pdf`

## Phase 2 — Content (in progress)
- [x] About me paragraph, LinkedIn link, CV download
- [x] Featured projects: role + 1–3 line description, link where one exists
- [x] Contact: LinkedIn + McCombs email
- [ ] Review and edit all copy in your own voice
- [ ] Add images for projects that still show a placeholder:
      CO2 AI, Email campaigns, Justin Khanna, Spinning Threads (book cover)
- [ ] Optional: a headshot next to the About paragraph

## Phase 3 — Polish
- [ ] Check on phone and desktop
- [ ] Pick a final accent color / font if you want something other than the default
- [ ] Add a favicon and page description (for link previews)

## Phase 4 — Publish
- [ ] Merge `site-setup` into `main` and push to GitHub
- [ ] Turn on GitHub Pages (Settings → Pages → deploy from `main`, root folder)
- [ ] Site goes live at `https://msuarez97.github.io/personalwebsite/`
- [ ] Optional: buy a custom domain (e.g. `mariasuarez.com`) and point it at GitHub Pages

## Phase 5 — Keep it fresh
- [ ] Update the CV file whenever your resume changes (same filename, so the link keeps working)
- [ ] Add new projects as you finish them (copy one `<article>` block in `index.html`)
